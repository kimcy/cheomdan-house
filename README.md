# 첨단디자인하우스

첨단하우스.com 원문 콘텐츠를 이관한 반응형 기업 홈페이지입니다. HTML/CSS/JavaScript로 작동하며 두 디자인을 함께 제공합니다.

- 1안 보관본: `http://localhost:4173/v1/` — 아이보리·딥그린 랜딩 페이지
- 기본 사이트(2안): `http://localhost:4173/` (기존 `/v2/` 주소도 유지) — 제공한 Figma Make 원본을 바탕으로 한 사진·명조체·올리브색 디자인
- 각 안에 회사소개, 연혁, 인증현황, 주택, 대피소, 동영상, 문의 등 하위 페이지 119개가 있습니다. 게시물 상세 100개를 포함합니다.

## 실행

```sh
npm install
npm run dev
```

http://localhost:4173 에서 확인합니다. CSS와 JavaScript를 읽을 수 있도록 로컬 서버로 열어 주세요.

## 검증 및 배포 파일

```sh
npm test
npm run build
node scripts/serve.mjs --dist
```

`dist/`에 정적 배포 파일을 생성합니다. 실제 도메인은 이 폴더를 만든 것만으로 변경되지 않습니다. 기존 홈페이지는 PHP/그누보드 기반이므로 운영 서버의 테마에 통합하거나 정적 호스팅에 연결해야 합니다. 기존 게시판과 관리자 파일을 덮어쓰지 마세요.

## 내용 관리

`content/site.json`에 원문 본문과 게시물 정보가 있습니다. `content/import-report.json`에 원본 이미지 수집 결과를 기록합니다. `content/recovery-audit.json`에는 원문 페이지 14곳과 누락 이미지의 원주소·연결 서버·웹 보관본 재확인 결과를 기록했습니다. 기존 사이트가 연결하는 관련 사이트에서 동일 경로의 대피소 이미지 2개를 복구했습니다. 원문 이미지 658개 중 593개를 로컬로 저장했고, 원본 서버에서 내려받을 수 없는 65개는 안내 문구로 표시합니다. 원본에 등록되지 않은 개인정보처리방침·이메일수집거부 페이지는 빈 상태를 유지합니다.

```sh
npm run import:content
npm run build
```

`templates/home-v1.html`이 1안 메인 원본이며, `scripts/prepare-v2.mjs`가 2안 메인을 생성합니다. `scripts/generate-pages.mjs`가 공유 콘텐츠로 두 안의 하위 페이지를 생성합니다. 생성된 `index.html`, `pages/`, `v2/pages/` 대신 템플릿과 생성기를 수정하세요.

1안 메인에는 원본 메인 사진 2장이 9초마다 페이드 전환되며 확대·이동하는 슬라이드가 있습니다. 사진 선택 버튼을 제공하며, 재생·일시정지 버튼 없이 동작 줄이기 설정과 관계없이 항상 자동 재생합니다. 메인 포트폴리오 사진 4개와 전체 모듈러주택 목록을 연결했습니다.

## 구현

- 히어로 및 전화·이메일 상담 CTA
- 세 가지 고민과 해결 카드
- 공식 홈페이지 이미지 4개, 필터 및 사진 확대
- 회사·공장 정보와 제품 유형별 견적 비교
- FAQ, 모바일 메뉴, 다크/라이트 모드, 스크롤 페이드인
- 키보드 접근성 및 동작 줄이기 설정 지원
- 전체 내부 메뉴, 하위 메뉴, 게시판 검색과 페이지 이동, 원본 이미지 확대
- 연혁 타임라인, 인증서 15건, 모듈러주택 35건, 빌리지 1건, 판넬 22건, 동영상 22건
- 2안 메인과 모든 하위 페이지의 일관된 Figma 디자인

문의 양식은 이메일 앱에서 메일 초안을 작성합니다. 홈페이지 직접 접수·게시판 관리 기능은 운영 서버의 PHP/그누보드 연동이 필요합니다. 원본의 연락처와 주소를 사용했고, 위치 페이지의 기존 주소·교통안내 불일치는 방문 전 확인 안내와 함께 보존했습니다. 메인과 하위 페이지의 주택 이미지는 기존 공식 홈페이지에서 가져왔습니다. 메인 히어로에는 원본 첫 화면의 배경 2장과 문구를, 제작 소개에는 원본 갤러리 이미지를, 모델 카드에는 S-38·AP-10·G-54의 원본 제품 이미지를 사용하고 해당 상세 페이지로 연결합니다. 출처는 `content/main-images.json`에 기록합니다.

가격과 후기 수치를 임의로 만들지 않고 원본에 안내된 상품 구성·연락처를 사용했습니다. 글꼴은 Google Fonts에서 불러오며 연결 실패 시 시스템 글꼴을 사용합니다.

모션은 히어로 순차 등장, 사진 줌, 스크롤 등장, 카드 지연, 호버 효과에 적용했습니다. 2안의 메인과 모든 하위 페이지는 브라우저 설정과 이전 저장값에 관계없이 항상 모션을 실행합니다. 별도의 모션 토글은 표시하지 않습니다.

2안 첫 화면은 원본 배경 2장(assets/hero.jpg, house-secondary.jpg)으로 9초 자동 전환, 1초 크로스페이드, 3초 사진 최초 등장·1.6초 문구 페이드인, 배경 확대·이동을 적용합니다. 포트폴리오 메뉴·메인 4개 카드·전체 목록 5개와 상세 화면을 추가했습니다. 원본 갤러리 상세는 포인트 제한으로 본문을 읽을 수 없어 공개 목록 이미지와 제목만 이관했습니다.

2안 메인 문구를 간결하게 정리하고 S-38 외관·실내, AP-10 조감도를 추가했습니다. 새 공간 소개 섹션에는 이미지 리빌과 16초 확대·이동을 적용하며, 화면 밖에서는 사진 애니메이션을 대기시켜 불필요한 렌더링을 줄입니다. 모바일에서는 한 열로 재배치합니다.

메인 히어로는 원본 배경 2장에 원본 갤러리 주택·쉼터 4장을 더해 총 6장으로 확대했습니다. 01–06 버튼으로 직접 선택할 수 있으며 이미지마다 문구가 바뀌고 마지막 사진 다음에는 첫 사진으로 돌아갑니다.

최종 메인 슬라이드는 사용자 요청에 따라 3장으로 조정했습니다. 원본 배경 2장과 이전 2안의 숲속 주택(reference-4.jpg)을 사용합니다. 1안의 주택 유형 비교·FAQ 4개·사진형 상담 영역을 원문 그대로 v2 스타일로 추가했으며 전화·이메일·공장 지도·맨 위로 이동을 연결했습니다.
